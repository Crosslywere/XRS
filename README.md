# XRS (Working name)

This is an OpenGL project that renders 3D or 2D scenes to a window

The goals are:

1. Handle scenes and camera specifications.
2. Handle transforms. (through a transform class)
3. Handle materials. (create a material struct)
4. Handle lighting.
5. Handle shadows.
6. Render to framebuffers.
7. Provide documentation for custom shaders.
